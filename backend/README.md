# TalentSphere Backend

This folder is a placeholder for the TalentSphere backend/API.

No backend requirements, data source, or API contract were specified for this
project yet, so nothing has been scaffolded here to avoid inventing endpoints
that don't match your real needs.

The frontend (`../frontend`) currently runs fully client-side with mock data
baked into `src/App.jsx` (see the `get D()` getter), matching the original
standalone demo.

When you're ready to add a real backend, let me know:
- the runtime/framework you want (Node/Express, Fastify, Django, etc.)
- the data store (Postgres, Mongo, etc.)
- which of the mocked entities (candidates, jobs, interviews, offers, etc.)
  need real persistence and endpoints

and I can scaffold it accordingly.
